# Roadmap

- Analytics/reporting: Add operational trends, exports, and configurable performance reports.
- Expanded roles/permissions: Add scoped capabilities beyond the initial administrator session.
- Delivery partners: Add rider assignment, availability, and delivery tracking workflows.
- Promotions/coupons: Add campaign, eligibility, redemption, and discount controls.
- Notifications: Add customer and operator messaging templates and delivery controls.
- Bulk import/export: Add validated batch workflows for catalog and inventory data.
- Multi-language: Add localized admin copy and catalog content management.
- Audit logs: Add searchable records for administrative actions and state changes.
